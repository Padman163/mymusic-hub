`NotationBuilder.astro` (`src/components/notation/NotationBuilder.astro`) ist die interaktive Editor-Erweiterung für das native SVG-Notationssystem. Sie basiert vollständig auf `<Notation />` (`src/components/notation/Notation.astro`), dem Bravura-SVG-Renderer (`src/lib/notation-renderer.ts`) und den Styles aus `src/styles/notation.css`.

> Alle allgemeinen musikalischen Regeln (wie Vorzeichen, Taktarten, Balken, Bögen und das `step`-Koordinatensystem von `-2` bis `10`) sind detailliert in der Dokumentation zu [Notation.astro](../notensystem/) beschrieben.

---

## 1. Standard-Darstellung

Standardmäßig erzeugt `<NotationBuilder />` ein leeres 1-Takt-System ohne linken und rechten Taktstrich (`showLeftBar={false}`, `showRightBar={false}`). Es kann genau eine Viertelnote per Tastatur oder Mausklick platziert werden:

```mdx
import NotationBuilder from "../../../../../components/notation/NotationBuilder.astro";

<NotationBuilder />
```

## 2. Kompakte Version (z. B. für Quiz / Übungen)

Mit der Prop `compact` (bzw. `compact="tight"` oder `compact="wide"`) beschränkt sich der Builder auf eine kompakte Breite (optimal für Übungen und Quizzes). Standardmäßig ist `compact={true}` genau so schmal wie in `<Notation compact />`. Mit `compact="wide"` wird ein lockererer Abstand verwendet. Notenschlüssel (`clef`), Tonartvorzeichen (`accidentals`) und Taktart (`timeSignature`) können optional übergeben werden:

```mdx
{/* Schmale Variante (Standard für compact) */}
<NotationBuilder
  compact
  clef="treble"
  timeSignature={{ numerator: 4, denominator: 4 }}
  accidentals={[{ type: "sharp", step: 8 }]}
/>

{/* Weitere Variante */}
<NotationBuilder
  compact="wide"
  clef="treble"
  timeSignature={{ numerator: 4, denominator: 4 }}
  accidentals={[{ type: "sharp", step: 8 }]}
/>
```

## 2. Interaktion & Steuerung

Die Bedienung erfolgt wahlweise per Maus oder Tastatur:

| Aktion | Tastatur / Maus | Verhalten |
| :--- | :--- | :--- |
| **Position wählen** | **Mausklick** ins Notensystem | Setzt den abgerundeten orangefarbenen Auswahlbereich auf die angeklickte vertikale Notenposition (`step`) sowie bei mehreren Noten (`maxNotes > 1`) auf den nächsten Slot. |
| **Slot wechseln** | **Pfeiltasten** `←` / `→` | Wechselt bei `maxNotes > 1` zwischen den Notenpositionen im Takt (auch auf noch leere Slots). |
| **Step anpassen** | **Pfeiltasten** `↑` / `↓` | Verschiebt die Auswahl schrittweise um eine Stufe nach oben oder unten (Halbton/Zwischenraum/Linie im Bereich `-2` bis `10`). |
| **Note setzen** | **`Leertaste`** | Platziert auf dem aktuellen Step eine Note mit dem gewählten Notenwert und springt bei `maxNotes > 1` automatisch zum nächsten Slot. |
| **Notenwert wählen** | **Toolbar-Klick** / **`Num 1`** (oder Ziffer `1`) | Schaltet durch die Notenwerte (Ganze → Halbe → Viertel → Achtel → 16tel) und aktualisiert eine gesetzte Note sofort (blockiert, wenn `lockDuration` aktiv ist). |
| **Note löschen** | **`Entf`** (`Delete` / `Backspace`) | Entfernt die gesetzte Note im aktiven Slot wieder. |

## 3. Builder-spezifische Props

Zusätzlich zu allen von `<Notation />` geerbten Attributen (`clef`, `timeSignature`, `accidentals`, `scale`, `showRightBar`, `rightBarStyle` etc.) bietet der Builder Parameter zur Steuerung von Hilfselementen:

| Prop | Typ | Standard | Beschreibung |
| :--- | :--- | :--- | :--- |
| `maxNotes` | `number` | `1` | Maximale Anzahl an Noten/Slots im Takt (z. B. `4` für vier Viertelnoten). |
| `lockDuration` | `Duration \| boolean` | `undefined` | Fester Notenwert (z. B. `"quarter"` oder `true`), sperrt Notenwertänderungen via Num 1 und Toolbar. |
| `initialStep` | `number` | `4` | Startposition des Markierungsbereichs (`4` = Mittellinie, Violinschlüssel: B4). |
| `initialDuration` | `Duration` | `"quarter"` | Standard-Notenwert für die Notenerstellung (`"whole" \| "half" \| "quarter" \| "eighth" \| "sixteenth"`). |
| `allowedDurations` | `Duration[]` | Alle 5 Werte | Array erlaubter Notenwerte für die Button-Leiste. |
| `showDurationPicker` | `boolean` | `false` | Blendet eine interaktive Button-Leiste (Toolbar) zur Auswahl des Notenwerts ein. |
| `compact` | `boolean \| "tight" \| "wide"` | `false` | Kompakte Breite (`"tight"` / `true` = halbe Breite von wide mit 150px, `"wide"` = Standard-Notationslänge mit 300px; beide standardmäßig ohne rechten Taktstrich). |
| `showLabel` | `boolean` | `false` | Blendet eine Noten- und Aktionsbeschriftung direkt am Auswahlbereich ein. |
| `showStatus` | `boolean` | `false` | Zeigt eine Statusleiste unterhalb des Systems mit Tonname und Aktion an. |
| `showHints` | `boolean` | `false` | Zeigt Tastatur-Bedienhinweise (im Footer oder bei `compact` als Spalte rechts) an. |

### Beispiel mit 4 Viertelnoten (`maxNotes={4}`)

```mdx
<NotationBuilder compact="wide" maxNotes={4} lockDuration="quarter" showHints />
```

## 4. DOM-Events & Quiz-Integration

Das Wurzelelement (`[data-notation-builder]`) synchronisiert den aktuellen Zustand fortlaufend über Data-Attribute und CustomEvents für umgebende Komponenten (z. B. `Level100Quiz.astro`):

- **Data-Attribute:** `data-cursor-step`, `data-cursor-note`, `data-placed-step`, `data-placed-note`, `data-placed-duration`, `data-active-duration`, `data-can-create`, `data-can-delete`, `data-max-notes`, `data-active-slot`, `data-placed-count`, `data-placed-steps`, `data-placed-notes`.
- **`notationbuilder:change`:** Wird bei jeder Positionsänderung, Notenerstellung, Notenwertänderung oder Löschung ausgelöst.
- **`notationbuilder:reset`:** Setzt den Editor zurück (optional mit neuer Startposition via `detail: { step }` und/oder Start-Notenwert via `detail: { duration }`).
- **`notationbuilder:set-duration`:** Ändert den aktiven Notenwert programmgesteuert via `detail: { duration }`.
