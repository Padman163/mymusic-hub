## Mehrere Takte mit Zeilenumbruch

Nach dem Import von `Notation` nimmt die Komponente die Takte direkt als `measures` entgegen (oder für einen einzelnen Takt die Kurzform `notes`). Über `layout` wird der Zeilenumbruch gesteuert: `'auto'` (Standard) bricht anhand der Mindestbreite um, eine Zahl wie `layout={3}` legt die maximale Anzahl pro Zeile fest, und ein Array wie `layout={[3, 1]}` definiert die Taktanzahl jeder Zeile explizit. Der Violinschlüssel steht automatisch am Anfang jeder Zeile; für den Bassschlüssel wird global oder im ersten Takt `clef="bass"` gesetzt. Taktart und Schlussstrich werden bei Bedarf am jeweiligen Takt angegeben.

```mdx
<Notation
  layout={3}
  timeSignature={{ numerator: 4, denominator: 4 }}
  measures={[
    { notes: [{ duration: 'whole', step: 2 }] },
    { notes: [{ duration: 'whole', step: 3 }] },
    { notes: [{ duration: 'whole', step: 4 }] },
    { rightBarStyle: 'final', notes: [{ duration: 'whole', step: 5 }] },
  ]}
/>
```

Hier mit Bassschlüssel, zwei Takten pro Zeile und aktiviertem horizontalem Scrollen (`scrollable`):

<Notation
  clef="bass"
  timeSignature={{ numerator: 4, denominator: 4 }}
  layout={2}
  scrollable
  measures={[
    { notes: [{ duration: 'whole', step: 2 }] },
    { notes: [{ duration: 'whole', step: 3 }] },
    { rightBarStyle: 'final', notes: [{ duration: 'whole', step: 4 }] },
  ]}
/>

Standardmäßig (`scrollable={false}`) passt sich das System automatisch der verfügbaren Breite an (`data-fit-to-width`), verteilt die Takte je Zeile passend und verkleinert das System bei Bedarf proportional, sodass die vorgegebene Taktzahl in die Breite passt. Eine unvollständige letzte Zeile nutzt bei `layout="auto"` oder einer festen Zahl ihren proportionalen Anteil am Platz (oder mit `stretchLastRow` die volle Zeilenbreite). Mit `scrollable` lässt sich der Kasten bei Platzmangel horizontal scrollen; auch ohne JavaScript oder bei fehlender Browser-Unterstützung bleibt das System scrollbar. `layout` als Zahl muss eine positive ganze Zahl sein; ein Schlüsselwechsel innerhalb derselben Zeile wird nicht unterstützt.

## Taktstriche

Das zweite Schaubild zeigt die Standardansicht mit einem Taktstrich rechts.

<Notation clef="treble" notes={[]} />

Die Taktstriche lassen sich beim Einbinden der Komponente unabhängig voneinander steuern: `showLeftBar` ist standardmäßig `false`, `showRightBar` standardmäßig `true`. Beispielsweise zeigt `<Notation showLeftBar={true} showRightBar={false} notes={[]} />` nur den linken Taktstrich.

## Notenschlüssel

Jede eigenständige Notenzeile zeigt standardmäßig einen Violinschlüssel. Für ein Beispiel kann `clef="bass"` den Bassschlüssel wählen. Innerhalb einer Notenzeile bleibt der Schlüssel unverändert; bei einem System mit `layout={1}` kann jede Zeile einen eigenen Schlüssel erhalten. Die Schlüssel verwenden die gleiche Notenschrift wie die AlphaTab-Beispiele.

## Notenköpfe

Gefüllte und ungefüllte Notenköpfe werden hier ohne Hals dargestellt. Sie sind zunächst nur vorgegeben und können noch nicht angeklickt oder eingezeichnet werden.

<Notation
  clef="treble"
  notes={[
    { type: 'filled', step: 0 },
    { type: 'empty', step: 2 },
    { type: 'filled', step: 5 },
    { type: 'empty', step: 8 },
  ]}
/>

Über `notes` werden Typ (`filled` oder `empty`) und Position (`step`) festgelegt. `step={0}` entspricht der untersten Linie, jeder weitere Schritt einem Linien- oder Zwischenraumabstand; `8` entspricht der obersten Linie. Die Notenköpfe werden von links nach rechts gleichmäßig verteilt. Zusätzlich sind die erste Hilfslinie unterhalb (`-2`) und oberhalb (`10`) des Systems verfügbar. Ein ungefüllter Notenkopf allein legt ohne weitere Notationszeichen keinen vollständigen Notenwert fest.

## Notenhälse

Für jeden Notenkopf kann über `stem: true` ein Hals eingeblendet werden. Ohne diese Angabe bleibt der Notenkopf ohne Hals. Unterhalb der mittleren Linie (`step < 4`) zeigt der Hals nach oben, ab der mittleren Linie (`step >= 4`) nach unten.

<Notation
  clef="treble"
  notes={[
    { type: 'filled', step: 0, stem: true },
    { type: 'empty', step: 3, stem: true },
    { type: 'filled', step: 4, stem: true },
    { type: 'empty', step: 8, stem: true },
  ]}
/>

## Taktarten

Das Schaubild zeigt 2/2, 2/4, 3/4, 4/4, 6/8 und 7/8 in einer Notenzeile. Taktstriche trennen die Beispiele.

<Notation
  clef="treble"
  layout={[6]}
  measureWidth="equal"
  measures={[
    { timeSignature: { numerator: 2, denominator: 2 }, notes: [] },
    { timeSignature: { numerator: 2, denominator: 4 }, notes: [] },
    { timeSignature: { numerator: 3, denominator: 4 }, notes: [] },
    { timeSignature: { numerator: 4, denominator: 4 }, notes: [] },
    { timeSignature: { numerator: 6, denominator: 8 }, notes: [] },
    { timeSignature: { numerator: 7, denominator: 8 }, rightBarStyle: 'final', notes: [] },
  ]}
/>

Bei `Notation` lassen sich mit `timeSignature` Zähler und Nenner global oder pro Takt festlegen; ohne Angabe wird keine Taktart angezeigt. Der Zähler muss eine positive ganze Zahl sein, der Nenner eine positive Zweierpotenz.

## Vorzeichen

Das Schaubild zeigt im Violinschlüssel fünf Kreuze (F, C, G, D, A), ihre fünf automatisch erzeugten Auflösungszeichen beim Wechsel nach C-Dur und anschließend fünf b-Vorzeichen (B, E, A, D, G). Im letzten Takt stehen einzelne Noten jeweils einmal mit Kreuz, Auflösungszeichen und b-Vorzeichen.

<Notation
  clef="treble"
  layout={[4]}
  measures={[
    {
      accidentals: [
        { type: 'sharp', step: 8 },
        { type: 'sharp', step: 5 },
        { type: 'sharp', step: 9 },
        { type: 'sharp', step: 6 },
        { type: 'sharp', step: 3 },
      ],
      notes: [],
    },
    {
      accidentals: [],
      notes: [],
    },
    {
      accidentals: [
        { type: 'flat', step: 4 },
        { type: 'flat', step: 7 },
        { type: 'flat', step: 3 },
        { type: 'flat', step: 6 },
        { type: 'flat', step: 2 },
      ],
      notes: [],
    },
    {
      rightBarStyle: 'final',
      notes: [
        { duration: 'quarter', step: 7, accidental: 'sharp' },
        { duration: 'quarter', step: 4, accidental: 'natural' },
        { duration: 'quarter', step: 2, accidental: 'flat' },
      ],
    },
  ]}
/>

Über `accidentals` lassen sich für die Tonartvorzeichnung die Zeichen `sharp` (Kreuz) und `flat` (b) mit einer Position `step` vorgeben; bei einem Wechsel oder `accidentals: []` ergänzt das Layout die erforderlichen Auflösungszeichen (`natural`) automatisch. Sie stehen nach dem Schlüssel und einer optionalen Taktart. Einzelne Noten können über die Eigenschaft `accidental` (`'sharp'`, `'natural'` oder `'flat'`) jeweils ein eigenes Versetzungszeichen erhalten.

## Noten- und Pausenwerte

Das Schaubild zeigt im ersten Takt die Noten und im zweiten Takt darunter die zugehörigen Pausen gleicher Dauer: von links nach rechts ganze, halbe, Viertel-, Achtel- und Sechzehntelwerte. Die ganze Pause hängt unter der vierten Notenlinie, die halbe liegt auf der dritten Linie (von unten gezählt). Eine ganze Pause kann außerdem einen vollständigen Takt beliebiger Taktart bezeichnen.

<Notation
  clef="treble"
  layout={1}
  measures={[
    {
      notes: [
        { duration: 'whole', step: 4 },
        { duration: 'half', step: 4 },
        { duration: 'quarter', step: 4 },
        { duration: 'eighth', step: 4 },
        { duration: 'sixteenth', step: 4 },
      ],
    },
    {
      rightBarStyle: 'final',
      notes: [
        { type: 'rest', duration: 'whole' },
        { type: 'rest', duration: 'half' },
        { type: 'rest', duration: 'quarter' },
        { type: 'rest', duration: 'eighth' },
        { type: 'rest', duration: 'sixteenth' },
      ],
    },
  ]}
/>

Mit `duration` zeigt `Notation` ganze (`whole`), halbe (`half`), Viertel- (`quarter`), Achtel- (`eighth`) und Sechzehntelnoten (`sixteenth`) an. Eine Pause wird in derselben `notes`-Liste mit `{ type: 'rest', duration: 'quarter' }` eingetragen und benötigt keine Tonhöhe. Noten und Pausen können gemischt werden; `dotted: true` punktiert auch eine Pause. Notenkopf, Hals und gegebenenfalls Fähnchen ergeben sich aus dem Notenwert; die Halsrichtung wird automatisch bestimmt.

Aufeinanderfolgende Achtel- oder Sechzehntelnoten können mit demselben `beamGroup`-Namen verbunden werden. Eine Gruppe benötigt mindestens zwei Noten und unterstützt sowohl Noten desselben Werts als auch die punktierte Kombination aus punktierter Achtel- und Sechzehntelnote. Die Halsrichtung richtet sich nach der Position jeder Note; bei wechselnden Halsrichtungen wird der Balken entsprechend angepasst.

<Notation
  clef="treble"
  notes={[
    { duration: 'eighth', step: 2, beamGroup: 'achtel' },
    { duration: 'eighth', step: 4, beamGroup: 'achtel' },
    { duration: 'sixteenth', step: 6, beamGroup: 'sechzehntel' },
    { duration: 'sixteenth', step: 4, beamGroup: 'sechzehntel' },
  ]}
/>

Für Noten und Pausen mit `duration` werden die Abstände linear nach ihren Dauern verteilt, einschließlich des Platzes nach dem letzten Ereignis. Eine Punktierung verlängert die Dauer um die Hälfte. Bei bekannter Taktart bleibt in unvollständigen Takten auch der nicht ausgefüllte Teil frei. Ohne bekannte Taktart gilt die Summe der Ereignisdauern als Taktlänge. Zwischen aufeinanderfolgenden Ereignissen bleibt mindestens ein Spatium frei. Notenköpfe ohne `duration` werden gleichmäßig verteilt, da keine rhythmischen Werte vorliegen.

Die linke Kante der ersten Note steht standardmäßig 1,5 Notenkopfbreiten nach dem Taktbeginn beziehungsweise nach Schlüssel, Taktart, Vorzeichnung und Wiederholungszeichen. Bei einem übervollen Takt mit bekannter Taktart steht auch die rechte Kante der letzten Note 1,5 Notenkopfbreiten vor dem Taktende; die Ereignisse dazwischen bleiben proportional verteilt. Hilfslinien, Vorzeichen, Punktierungen, Fähnchen und Schluss- oder Wiederholungszeichen können zusätzlichen Platz benötigen. Eine einzelne Note steht am Anfang; eine einzelne unpunktierte ganze Taktpause bleibt mittig. Ein explizites `firstNoteX` oder die spaltenweise Ausrichtung im Notensystem kann den Beginn verschieben.

`Notation` übernimmt die zuletzt angegebene Taktart für das Layout der folgenden Takte (`layoutTimeSignature`), ohne sie erneut anzuzeigen. Soll eine Taktart nur für die Abstandsberechnung gelten, ohne ein Taktzeichen darzustellen, kann `layoutTimeSignature={{ numerator: 4, denominator: 4 }}` am Takt gesetzt werden. `timeSignature` hat Vorrang, wenn beides gesetzt ist.

## Punktierte Noten

Ein Punkt rechts neben dem Notenkopf verlängert den Notenwert um die Hälfte. Das Schaubild zeigt in drei Takten eine punktierte halbe Note (3 Viertelschläge), eine punktierte Viertelnote (3 Achtelschläge) und eine punktierte Achtelnote (3 Sechzehntelschläge), jeweils ergänzt zum 4/4-Takt.

## Schlussstrich

Der Schlussstrich besteht aus einer dünnen und einer dicken Linie. `Notation` stellt ihn mit `rightBarStyle="final"` dar; damit ersetzt er den einfachen rechten Taktstrich. Mit `showRightBar={false}` wird er ausgeblendet.

<Notation clef="treble" rightBarStyle="final" notes={[]} />

## Auftakt und Wiederholung

Das Beispiel im 4/4-Takt beginnt mit einem Auftakt (`pickup`) von einer Viertelnote. Danach folgen die nummerierten Takte 1 bis 4. Die Wiederholungszeichen (`repeatStart` und `repeatEnd`) schließen Takt 2 und 3 ein: Nach Takt 3 werden diese beiden Takte einmal wiederholt, bevor Takt 4 folgt. Das Endzeichen steht direkt am Taktende: zwei Punkte links, danach ein dünner und ein dicker Strich; es ersetzt dort den einfachen Taktstrich. Der letzte Takt enthält drei Viertelnoten und ergänzt damit den Auftakt automatisch zu einem vollständigen 4/4-Takt.

<Notation
  clef="treble"
  timeSignature={{ numerator: 4, denominator: 4 }}
  pickup
  layout={[3, 2]}
  measures={[
    {
      notes: [{ duration: 'quarter', step: 2 }],
    },
    {
      measureNumber: 1,
      notes: [
        { duration: 'quarter', step: 3 },
        { duration: 'quarter', step: 4 },
        { duration: 'quarter', step: 5 },
        { duration: 'quarter', step: 2 },
      ],
    },
    {
      measureNumber: 2,
      repeatStart: true,
      notes: [
        { duration: 'quarter', step: 5 },
        { duration: 'quarter', step: 6 },
        { duration: 'quarter', step: 5 },
        { duration: 'quarter', step: 4 },
      ],
    },
    {
      measureNumber: 3,
      repeatEnd: true,
      notes: [
        { duration: 'quarter', step: 3 },
        { duration: 'quarter', step: 2 },
        { duration: 'quarter', step: 1 },
        { duration: 'quarter', step: 2 },
      ],
    },
    {
      measureNumber: 4,
      rightBarStyle: 'final',
      notes: [
        { duration: 'quarter', step: 3 },
        { duration: 'quarter', step: 2 },
        { duration: 'quarter', step: 0 },
      ],
    },
  ]}
/>

Taktnummern werden pro Takt über `measureNumber` eingeblendet; `pickup` prüft automatisch, dass sich erster und letzter Takt zu einem vollen Takt ergänzen, und gewichtet ihre Spaltenbreiten passend.

## Tempoangaben

Das Beispiel zeigt zwei 4/4-Takte mit **Allegro** (`tempo="Allegro"`) und der Metronomangabe **♩ = 90** (`tempoDetail="♩ = 90"`, 90 Viertelschläge pro Minute). Im zweiten Takt bedeutet **rit.**, allmählich langsamer zu werden; **a tempo** führt zum ursprünglichen Tempo zurück. Beide Angaben werden über `ritAt` und `aTempoAt` an nullbasierten Notenindizes gebunden. `aTempoAt` muss im selben Takt mindestens zwei Indizes Abstand zu `ritAt` haben.

Für Dynamik- und Tempotexte gelten zwei visuelle Größen: `cresc.`, `decresc.`, `rit.`, `a tempo` und Metronomdetails sind klein; die fette Tempoüberschrift ist optisch auf die Dynamikzeichen **p** und **f** abgestimmt. Da die Notenschrift andere Zeichenabmessungen als die Textschrift hat, unterscheiden sich ihre CSS-Schriftgrößen.

<Notation
  clef="treble"
  timeSignature={{ numerator: 4, denominator: 4 }}
  layout={2}
  measures={[
    {
      tempo: 'Allegro',
      tempoDetail: '♩ = 90',
      notes: [
        { duration: 'quarter', step: 0 },
        { duration: 'quarter', step: 1 },
        { duration: 'quarter', step: 2 },
        { duration: 'quarter', step: 3 },
      ],
    },
    {
      ritAt: 0,
      aTempoAt: 2,
      rightBarStyle: 'final',
      notes: [
        { duration: 'quarter', step: 2 },
        { duration: 'quarter', step: 3 },
        { duration: 'quarter', step: 4 },
        { duration: 'quarter', step: 5 },
      ],
    },
  ]}
/>

## Artikulation

Artikulationszeichen beschreiben, wie ein Ton gespielt und gestaltet wird. Das Beispiel zeigt **Staccato** (`staccato`), **Tenuto** (`tenuto`), **Akzent** (`accent`) und **Marcato** (`marcato`) im ersten Takt oberhalb (`articulationPosition: 'above'`) und im zweiten Takt unterhalb (`articulationPosition: 'below'`) einer Note. Die Platzierung erfolgt standardmäßig auf der dem Notenhals abgewandten Seite und kann über `articulationPosition` explizit oben oder unten festgelegt werden: Staccato verkürzt den Ton, Tenuto hält ihn voll aus, der Akzent hebt ihn hervor und Marcato markiert einen besonders kräftigen Anschlag.

<Notation
  clef="treble"

  layout={2}
  measureWidth="equal"
  measures={[

      notes: [

        { duration: 'quarter', step: 7, articulation: 'tenuto', articulationPosition: 'above' },
        { duration: 'quarter', step: 7, articulation: 'accent', articulationPosition: 'above' },
        { duration: 'quarter', step: 7, articulation: 'marcato', articulationPosition: 'above' },
      ],
    },
    {
      rightBarStyle: 'final',
      notes: [
        { duration: 'quarter', step: 2, articulation: 'staccato', articulationPosition: 'below' },
        { duration: 'quarter', step: 2, articulation: 'tenuto', articulationPosition: 'below' },
        { duration: 'quarter', step: 2, articulation: 'accent', articulationPosition: 'below' },
        { duration: 'quarter', step: 2, articulation: 'marcato', articulationPosition: 'below' },
      ],
    },
  ]}
/>

## Haltebogen und Bindebogen

Ein **Haltebogen** (`type: 'tie'`) verbindet Noten gleicher Tonhöhe; die Notenwerte werden zu einem gehaltenen Ton zusammengefasst. Ein **Bindebogen** (`type: 'slur'`) verbindet unterschiedliche Tonhöhen und zeigt an, dass sie gebunden (legato) gespielt werden.

<Notation
  clef="treble"
  layout={1}
  measures={[
    {
      curves: [{ from: 0, to: 1, type: 'tie', placement: 'below' }],
      notes: [
        { duration: 'quarter', step: 0 },
        { duration: 'quarter', step: 0 },
        { duration: 'quarter', step: 2 },
        { duration: 'quarter', step: 4 },
      ],
    },
    {
      rightBarStyle: 'final',
      curves: [{ from: 2, to: 3, type: 'slur', placement: 'below' }],
      notes: [
        { duration: 'quarter', step: 0, articulation: 'accent', articulationPosition: 'below' },
        { duration: 'quarter', step: 0, articulation: 'accent', articulationPosition: 'below' },
        { duration: 'quarter', step: 2 },
        { duration: 'quarter', step: 4 },
      ],
    },
  ]}
/>

## Dynamik

Dynamikzeichen geben an, wie laut oder leise gespielt wird. **p** (*piano*) bedeutet leise, **f** (*forte*) laut. Ein Crescendo (*cresc.*) wird durch einen nach rechts weiter werdenden Keil dargestellt und bedeutet, allmählich lauter zu werden. Ein Decrescendo (*decresc.*) verengt sich nach rechts und bedeutet, allmählich leiser zu werden. In `Notation` lassen sich Dynamikstufen direkt an einzelnen Noten über `dynamic` (sowie `dynamicText`) angeben und Dynamikgabeln entweder pro Takt über `hairpin="crescendo"` beziehungsweise `hairpin="decrescendo"` oder notengenau (auch taktübergreifend) über `hairpinStart` und `hairpinEnd` spannen.

<Notation
  clef="treble"
  timeSignature={{ numerator: 4, denominator: 4 }}
  layout={2}
  measures={[
    {
      hairpin: 'crescendo',
      notes: [

        { duration: 'quarter', step: 4 },
        { duration: 'quarter', step: 3 },
        { duration: 'quarter', step: 4, dynamic: 'f' },
      ],
    },
    {
      hairpin: 'decrescendo',

## Abschlussbeispiel: achtzehn Takte

Das abschließende Testbeispiel bündelt Notationszeichen in achtzehn vollständigen, nummerierten Takten im Violinschlüssel. Die Takte 1 bis 8 und 13 bis 15 stehen im 4/4-Takt, die Takte 9 bis 12 und 16 bis 18 im 3/4-Takt. Die Taktart steht nur am Anfang und beim Wechsel. Es enthält eine Tonartvorzeichnung, einzelne Kreuze, Bs und Auflösungszeichen, Hilfslinien, ganze bis Sechzehntelnoten, Punktierung, Fähnchen und Balkengruppen, Artikulationen oberhalb und unterhalb von Noten, Halte- und Bindebögen, Allegro, rit. und a tempo mit mindestens zwei Notenpositionen Abstand, Crescendo und Decrescendo, Wiederholungszeichen sowie den Schlussstrich. In den letzten sechs Takten stehen ganze, halbe, Viertel- und Achtelpausen.

Mit `layout={[2, 2, 2, 2, 2, 2, 3, 3]}` stehen die ersten zwölf Takte zu zweit, die letzten sechs zu dritt in einem System. Jede Zeile beginnt mit dem Violinschlüssel und der aktuell gültigen Tonartvorzeichnung. Bei Bedarf wird die Übersicht über `observeNotationFit` proportional verkleinert; ohne JavaScript oder Browser-Unterstützung bleibt sie scrollbar. Alle Systeme werden deklarativ durch `Notation` über `layoutNotationSystems` und `NotationVisual` aufgebaut. `renderNotationSvg` ordnet Notenschlüssel, Vorzeichen, Noten, Pausen und Dynamik im Notensystem an und nutzt für gemeinsame musikalische Zeichen und Regeln die Module in `src/lib/`. Taktzahlen kommen aus `MeasureNumber`, Tempoangaben aus `TempoLabel`, der Schlussstrich aus `FinalBar`. Ein gesetztes `accidentals`-Array bezeichnet die neue Tonartvorzeichnung; ein leeres Array hebt sie auf, fehlende Angaben behalten die bisherige Vorzeichnung bei. Bei einem Wechsel werden aufgehobene Vorzeichen automatisch mit Auflösungszeichen dargestellt. Einzelne `accidental`-Angaben an Noten verändern die Vorzeichnung nicht.

Für mehrzeilige Darstellungen bestimmen `arrangeNotationSystems` und `alignFirstNotesInSystems` eine gemeinsame Position für das erste Ereignis: am Systemanfang auch bei unterschiedlich vielen Takten pro Zeile, in den folgenden Takten mit einem einheitlichen Abstand zum Taktstrich. Das gilt für Noten ebenso wie für Pausen; eine einzelne ganze Taktpause bleibt mittig. Dabei wird genug Platz für Schlüssel, Taktart, Vorzeichnung, Wiederholungszeichen und gegebenenfalls das Vorzeichen der ersten Note reserviert. Die Zeilen in `.notation-systems` reservieren über `.has-row-measure-number`, `.has-row-tempo` und `.has-row-hairpin` automatisch die nötigen vertikalen Sicherheitszonen.

Die horizontalen Positionen der Ereignisse berechnet `layoutNotationEvents` in `src/lib/notation-layout.ts` unabhängig von der SVG-Ausgabe. Der Renderer verwendet diese Positionen auch für Mindestbreite, Balken, Bögen, Dynamikgabeln und Tempoangaben. Die Aufteilung der Takte auf Zeilen und die Grid-Spaltenbreiten steuert `src/lib/system-layout.ts`.

| Zeichen im Test | Baustein | Regel oder Verwendung |
|---|---|---|
| Violinschlüssel, Notenköpfe, Hilfslinien und Vorzeichen | `Notation`, `NotationVisual`, `renderNotationSvg` | Am Zeilenbeginn stehen Schlüssel, gegebenenfalls Taktart und gültige Vorzeichnung in dieser Reihenfolge. |
| Taktarten 4/4 und 3/4 | `src/lib/time-signature.ts` | Nur am Stückanfang und beim Wechsel anzeigen (`omitUnchangedTimeSignatures`). |
| Ganze bis Sechzehntelnoten, Punkt, Fähnchen und Balken | `src/lib/rhythm.ts` und `renderNotationSvg` | Balkengruppen bestehen aus zusammenhängenden Achteln, Sechzehnteln oder punktierten Achtel-Sechzehntel-Figuren. |
| Pausen | `src/lib/rest.ts` und `renderNotationSvg` | Pausen können mit Noten gemischt werden; die ganze Pause in Takt 15 füllt den 4/4-Takt und steht mittig im verfügbaren Taktbereich. |
