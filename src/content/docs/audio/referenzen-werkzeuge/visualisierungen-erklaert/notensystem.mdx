## Grundansicht

Das erste Schaubild zeigt fünf Notenlinien auf weißem Hintergrund, ohne Taktstriche. Die Komponente ist noch in Entwicklung; Noten können derzeit noch nicht eingezeichnet werden.

<NotationClickable showRightBar={false} />

## Taktstriche

Das zweite Schaubild zeigt die Standardansicht mit einem Taktstrich rechts.

<NotationClickable />

Die Taktstriche lassen sich beim Einbinden der Komponente unabhängig voneinander steuern: `showLeftBar` ist standardmäßig `false`, `showRightBar` standardmäßig `true`. Beispielsweise zeigt `<NotationClickable showLeftBar={true} showRightBar={false} />` nur den linken Taktstrich.

## Notenköpfe

Gefüllte und ungefüllte Notenköpfe werden hier ohne Hals dargestellt. Sie sind zunächst nur vorgegeben und können noch nicht angeklickt oder eingezeichnet werden.

<NotationClickable notes={[
  { type: 'filled', step: 0 },
  { type: 'empty', step: 2 },
  { type: 'filled', step: 5 },
  { type: 'empty', step: 8 }
]} />

Über `notes` werden Typ (`filled` oder `empty`) und Position (`step`) festgelegt. `step={0}` entspricht der untersten Linie, jeder weitere Schritt einem Linien- oder Zwischenraumabstand; `8` entspricht der obersten Linie. Die Notenköpfe werden von links nach rechts gleichmäßig verteilt. Zusätzlich sind die erste Hilfslinie unterhalb (`-2`) und oberhalb (`10`) des Systems verfügbar. Ein ungefüllter Notenkopf allein legt ohne weitere Notationszeichen keinen vollständigen Notenwert fest.

## Notenhälse

Für jeden Notenkopf kann über `stem: true` ein Hals eingeblendet werden. Ohne diese Angabe bleibt der Notenkopf ohne Hals. Unterhalb der mittleren Linie zeigt der Hals nach oben, ab der mittleren Linie nach unten.

<NotationClickable clef="treble" notes={[
  { type: 'filled', step: 0, stem: true },
  { type: 'empty', step: 3, stem: true },
  { type: 'filled', step: 4, stem: true },
  { type: 'empty', step: 8, stem: true }
]} />

## Taktarten

Das Schaubild zeigt 2/2, 2/4, 3/4, 4/4, 6/8 und 7/8 in einer Notenzeile. Taktstriche trennen die Beispiele.

<NotationTimeSignatures timeSignatures={[
  { numerator: 2, denominator: 2 },
  { numerator: 2, denominator: 4 },
  { numerator: 3, denominator: 4 },
  { numerator: 4, denominator: 4 },
  { numerator: 6, denominator: 8 },
  { numerator: 7, denominator: 8 }
]} />

Bei `NotationClickable` lassen sich mit `timeSignature` Zähler und Nenner festlegen; ohne Angabe wird keine Taktart angezeigt. Der Zähler muss eine positive ganze Zahl sein, der Nenner eine positive Zweierpotenz. Für die gemeinsame Darstellung nimmt `NotationTimeSignatures` eine Liste dieser Taktarten entgegen.

## Vorzeichen

Das Schaubild zeigt im Violinschlüssel fünf Kreuze (F, C, G, D, A), ihre fünf Auflösungszeichen und anschließend fünf b-Vorzeichen (B, E, A, D, G). Die Taktstriche trennen die drei Beispiele.

<NotationAccidentals />

Über `accidentals` lassen sich die Zeichen `sharp` (Kreuz), `natural` (Auflösungszeichen) und `flat` (b) mit einer Position `step` vorgeben. Sie stehen nach dem Schlüssel und vor einer optionalen Taktart. Die Komponente stellt die Zeichen dar, berechnet aber noch keine Tonart oder Tonhöhenänderung.

## Notenwerte

Mit `duration` zeigt die Komponente ganze (`whole`), halbe (`half`), Viertel- (`quarter`), Achtel- (`eighth`) und Sechzehntelnoten (`sixteenth`) an. Notenkopf, Hals und gegebenenfalls Fähnchen ergeben sich aus dem Notenwert; die Halsrichtung wird automatisch bestimmt.

<NotationClickable clef="treble" notes={[
  { duration: 'whole', step: 2 },
  { duration: 'half', step: 2 },
  { duration: 'quarter', step: 2 },
  { duration: 'eighth', step: 2 },
  { duration: 'sixteenth', step: 2 }
]} />

Aufeinanderfolgende Achtel- oder Sechzehntelnoten desselben Werts können mit demselben `beamGroup`-Namen verbunden werden. Eine Gruppe benötigt mindestens zwei Noten und erhält eine gemeinsame Halsrichtung. Gemischte Notenwerte innerhalb einer Gruppe sind noch nicht vorgesehen.

<NotationClickable clef="treble" notes={[
  { duration: 'eighth', step: 2, beamGroup: 'achtel' },
  { duration: 'eighth', step: 2, beamGroup: 'achtel' },
  { duration: 'sixteenth', step: 6, beamGroup: 'sechzehntel' },
  { duration: 'sixteenth', step: 6, beamGroup: 'sechzehntel' }
]} />

Die Beispiele zeigen die Zeichen zur Veranschaulichung; die Komponente prüft noch nicht, ob Notenwerte zusammen zur Taktart passen.

## Klaviaturnotation

Das Klaviersystem zeigt oben den Violin- und unten den Bassschlüssel. Das mittlere C (C4) steht im oberen System auf der ersten Hilfslinie darunter und im unteren System auf der ersten Hilfslinie darüber. Beide Darstellungen liegen hier genau übereinander und zeigen denselben Ton.

<KeyboardNotation />

Der Schlussstrich erstreckt sich über beide Systeme. Mit `rightBarStyle="single"` erscheinen stattdessen die einfachen Taktstriche. Die geschweifte Klammer ist standardmäßig sichtbar und lässt sich beim Einbinden mit `<KeyboardNotation showBrace={false} />` ausblenden.

Die Visualisierung trägt die Tags `Allgemein` und `Notensystem`. Mehr zur geplanten Verwendung steht unter [EXP und Tags](../../exp-und-tags/).


## Auftakt und Wiederholung

Das Beispiel im 4/4-Takt beginnt mit einem Auftakt von einer Viertelnote. Danach folgen die nummerierten Takte 1 bis 4. Die Wiederholungszeichen schließen Takt 2 und 3 ein: Nach Takt 3 werden diese beiden Takte einmal wiederholt, bevor Takt 4 folgt. Der letzte Takt enthält drei Viertelnoten und ergänzt damit den Auftakt zu einem vollständigen 4/4-Takt.

<NotationPickupRepeat showMeasureNumbers={true} />

Taktnummern sind standardmäßig ausgeblendet und werden in diesem Beispiel mit `showMeasureNumbers={true}` eingeblendet.

## Tempoangaben

Das Beispiel zeigt zwei 4/4-Takte mit **Allegro** und der Metronomangabe **Viertelnote = 90** (90 Viertelschläge pro Minute). Im zweiten Takt bedeutet **rit.**, allmählich langsamer zu werden; **a tempo** führt zum ursprünglichen Tempo zurück. Die Zahl ist hier die konkrete Tempovorgabe.

## Artikulation

Artikulationszeichen beschreiben, wie ein Ton gespielt und gestaltet wird. Das Beispiel zeigt **Staccato**, **Tenuto**, **Akzent** und **Marcato** jeweils oberhalb und unterhalb einer Note. Die Platzierung kann je nach Notenbild oberhalb oder unterhalb erfolgen: Staccato verkürzt den Ton, Tenuto hält ihn voll aus, der Akzent hebt ihn hervor und Marcato markiert einen besonders kräftigen Anschlag.

<NotationArticulations />

## Haltebogen und Bindebogen

Ein **Haltebogen** verbindet Noten gleicher Tonhöhe; die Notenwerte werden zu einem gehaltenen Ton zusammengefasst. Ein **Bindebogen** verbindet unterschiedliche Tonhöhen und zeigt an, dass sie gebunden (legato) gespielt werden.

<NotationBows />

## Dynamik

Dynamikzeichen geben an, wie laut oder leise gespielt wird. **p** (*piano*) bedeutet leise, **f** (*forte*) laut. Ein Crescendo (*cresc.*) wird durch einen nach rechts weiter werdenden Keil dargestellt und bedeutet, allmählich lauter zu werden. Ein Decrescendo (*decresc.*) verengt sich nach rechts und bedeutet, allmählich leiser zu werden.
