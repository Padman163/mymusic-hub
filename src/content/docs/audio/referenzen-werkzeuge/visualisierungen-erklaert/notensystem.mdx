Das erste Schaubild zeigt fünf Notenlinien auf weißem Hintergrund, ohne Taktstriche.

## Taktstriche

Das zweite Schaubild zeigt die Standardansicht mit einem Taktstrich rechts.

<NotationVisual />

Die Taktstriche lassen sich beim Einbinden der Komponente unabhängig voneinander steuern: `showLeftBar` ist standardmäßig `false`, `showRightBar` standardmäßig `true`. Beispielsweise zeigt `<NotationVisual showLeftBar={true} showRightBar={false} />` nur den linken Taktstrich.

## Notenschlüssel

Jede eigenständige Notenzeile zeigt standardmäßig einen Violinschlüssel. Für ein einzelnes Beispiel kann `clef="bass"` den Bassschlüssel wählen. Innerhalb eines Stücks, das von einer `.astro`-Komponente aufgebaut wird, bleibt der Schlüssel jedoch unverändert; `assertNoClefChanges` prüft das. Mit `clef={false}` wird der Schlüssel ausgeblendet, zum Beispiel bei weiteren Takten oder Systemen desselben Stücks. Die Schlüssel verwenden die gleiche Notenschrift wie die AlphaTab-Beispiele.

## Notenköpfe

Gefüllte und ungefüllte Notenköpfe werden hier ohne Hals dargestellt. Sie sind zunächst nur vorgegeben und können noch nicht angeklickt oder eingezeichnet werden.

<NotationVisual notes={[
  { type: 'filled', step: 0 },
  { type: 'empty', step: 2 },
  { type: 'filled', step: 5 },
  { type: 'empty', step: 8 }
]} />

Über `notes` werden Typ (`filled` oder `empty`) und Position (`step`) festgelegt. `step={0}` entspricht der untersten Linie, jeder weitere Schritt einem Linien- oder Zwischenraumabstand; `8` entspricht der obersten Linie. Die Notenköpfe werden von links nach rechts gleichmäßig verteilt. Zusätzlich sind die erste Hilfslinie unterhalb (`-2`) und oberhalb (`10`) des Systems verfügbar. Ein ungefüllter Notenkopf allein legt ohne weitere Notationszeichen keinen vollständigen Notenwert fest.

## Notenhälse

Für jeden Notenkopf kann über `stem: true` ein Hals eingeblendet werden. Ohne diese Angabe bleibt der Notenkopf ohne Hals. Unterhalb der mittleren Linie zeigt der Hals nach oben, ab der mittleren Linie nach unten.

<NotationVisual clef="treble" notes={[
  { type: 'filled', step: 0, stem: true },
  { type: 'empty', step: 3, stem: true },
  { type: 'filled', step: 4, stem: true },
  { type: 'empty', step: 8, stem: true }
]} />

## Taktarten

Das Schaubild zeigt 2/2, 2/4, 3/4, 4/4, 6/8 und 7/8 in einer Notenzeile. Taktstriche trennen die Beispiele.

<NotationTimeSignatures timeSignatures={[
  { numerator: 2, denominator: 2 },
  { numerator: 2, denominator: 4 },
  { numerator: 3, denominator: 4 },
  { numerator: 4, denominator: 4 },
  { numerator: 6, denominator: 8 },
  { numerator: 7, denominator: 8 }
]} />

Bei `NotationVisual` lassen sich mit `timeSignature` Zähler und Nenner festlegen; ohne Angabe wird keine Taktart angezeigt. Der Zähler muss eine positive ganze Zahl sein, der Nenner eine positive Zweierpotenz. Für die gemeinsame Darstellung nimmt `NotationTimeSignatures` eine Liste dieser Taktarten entgegen.

## Vorzeichen

Das Schaubild zeigt im Violinschlüssel fünf Kreuze (F, C, G, D, A), ihre fünf Auflösungszeichen und anschließend fünf b-Vorzeichen (B, E, A, D, G). Im letzten Takt stehen einzelne Noten jeweils einmal mit Kreuz, Auflösungszeichen und b-Vorzeichen.

<NotationAccidentals />

Über `accidentals` lassen sich die Zeichen `sharp` (Kreuz), `natural` (Auflösungszeichen) und `flat` (b) mit einer Position `step` vorgeben. Sie stehen nach dem Schlüssel und einer optionalen Taktart. Einzelne Noten können über die Eigenschaft `accidental` ebenfalls jeweils ein eigenes Vorzeichen erhalten. Die Komponente stellt die Zeichen dar, berechnet aber noch keine Tonart oder Tonhöhenänderung.

## Noten- und Pausenwerte

Das Schaubild zeigt oben die Noten und darunter die zugehörigen Pausen gleicher Dauer: von links nach rechts ganze, halbe, Viertel-, Achtel- und Sechzehntelwerte. Die ganze Pause hängt unter der vierten Notenlinie, die halbe liegt auf der dritten Linie (von unten gezählt). Eine ganze Pause kann außerdem einen vollständigen Takt beliebiger Taktart bezeichnen.

<NotationNoteRestValues />

Mit `duration` zeigt `NotationVisual` ganze (`whole`), halbe (`half`), Viertel- (`quarter`), Achtel- (`eighth`) und Sechzehntelnoten (`sixteenth`) an. Eine Pause wird in derselben `notes`-Liste mit `{ type: 'rest', duration: 'quarter' }` eingetragen und benötigt keine Tonhöhe. Noten und Pausen können gemischt werden; `dotted: true` punktiert auch eine Pause. Notenkopf, Hals und gegebenenfalls Fähnchen ergeben sich aus dem Notenwert; die Halsrichtung wird automatisch bestimmt.

Aufeinanderfolgende Achtel- oder Sechzehntelnoten desselben Werts können mit demselben `beamGroup`-Namen verbunden werden. Eine Gruppe benötigt mindestens zwei Noten. Die Halsrichtung richtet sich nach der Position jeder Note; bei wechselnden Halsrichtungen wird der Balken entsprechend geknickt. Gemischte Notenwerte innerhalb einer Gruppe sind noch nicht vorgesehen.

<NotationVisual clef="treble" notes={[
  { duration: 'eighth', step: 2, beamGroup: 'achtel' },
  { duration: 'eighth', step: 4, beamGroup: 'achtel' },
  { duration: 'sixteenth', step: 6, beamGroup: 'sechzehntel' },
  { duration: 'sixteenth', step: 4, beamGroup: 'sechzehntel' }
]} />

Für Noten und Pausen mit `duration` wachsen die Abstände optisch komprimiert mit der Dauer: Eine Verdopplung der Dauer ergibt ungefähr den 1,414-fachen Abstand, eine Punktierung das 1,3-Fache. Der verbleibende Abstand zum Taktende wird nach demselben Verhältnis berechnet. Zwischen aufeinanderfolgenden Ereignissen bleibt mindestens ein Spatium frei; bei schmalen Darstellungen kann horizontal gescrollt werden. Eine einzelne ganze Note steht bei 41 % der Taktbreite. Die Komponente prüft noch nicht, ob die Werte zusammen zur Taktart passen. Unvollständige Notenköpfe ohne `duration` werden weiterhin gleichmäßig verteilt. Für reine Zeichenvergleiche wie das obige Schaubild kann mit `spacing="equal"` eine gleichmäßige Verteilung gewählt werden.

## Klaviaturnotation

Das Klaviersystem zeigt oben den Violin- und unten den Bassschlüssel. Das mittlere C (C4) steht im oberen System auf der ersten Hilfslinie darunter und im unteren System auf der ersten Hilfslinie darüber. Beide Darstellungen liegen hier genau übereinander und zeigen denselben Ton.

<NotationKeyboard />

Der Schlussstrich erstreckt sich über beide Systeme. Mit `rightBarStyle="single"` erscheinen stattdessen die einfachen Taktstriche. Die geschweifte Klammer ist standardmäßig sichtbar und lässt sich beim Einbinden mit `<NotationKeyboard showBrace={false} />` ausblenden.

Die Visualisierung trägt die Tags `Allgemein` und `Notensystem`. Mehr zur geplanten Verwendung steht unter [EXP und Tags](../../exp-und-tags/).


## Auftakt und Wiederholung

Das Beispiel im 4/4-Takt beginnt mit einem Auftakt von einer Viertelnote. Danach folgen die nummerierten Takte 1 bis 4. Das Anfangswiederholungszeichen steht nach dem Notenschlüssel. Die Wiederholungszeichen schließen Takt 2 und 3 ein: Nach Takt 3 werden diese beiden Takte einmal wiederholt, bevor Takt 4 folgt. Das Endzeichen steht direkt am Taktende: zwei Punkte links, danach ein dünner und ein dicker Strich; es ersetzt dort den einfachen Taktstrich. Der letzte Takt enthält drei Viertelnoten und ergänzt damit den Auftakt zu einem vollständigen 4/4-Takt.

<NotationPickupRepeat showMeasureNumbers={true} />

Taktnummern sind standardmäßig ausgeblendet und werden in diesem Beispiel mit `showMeasureNumbers={true}` eingeblendet.

## Tempoangaben

Das Beispiel zeigt zwei 4/4-Takte mit **Allegro** und der Metronomangabe **Viertelnote = 90** (90 Viertelschläge pro Minute). Im zweiten Takt bedeutet **rit.**, allmählich langsamer zu werden; **a tempo** führt zum ursprünglichen Tempo zurück. Beide Angaben werden über `ritAt` und `aTempoAt` direkt an `NotationVisual` an nullbasierten Notenindizes gebunden. `aTempoAt` muss mindestens zwei Indizes nach `ritAt` liegen; dieselbe oder eine frühere Note ist unzulässig.

Für Dynamik- und Tempotexte gelten zwei visuelle Größen: `cresc.`, `decresc.`, `rit.`, `a tempo` und Metronomdetails sind klein; die fette Tempoüberschrift ist optisch auf die Dynamikzeichen **p** und **f** abgestimmt. Da die Notenschrift andere Zeichenabmessungen als die Textschrift hat, unterscheiden sich ihre CSS-Schriftgrößen.

<NotationTempo />

## Artikulation

Artikulationszeichen beschreiben, wie ein Ton gespielt und gestaltet wird. Das Beispiel zeigt **Staccato**, **Tenuto**, **Akzent** und **Marcato** jeweils oberhalb und unterhalb einer Note. Die Platzierung kann je nach Notenbild oberhalb oder unterhalb erfolgen: Staccato verkürzt den Ton, Tenuto hält ihn voll aus, der Akzent hebt ihn hervor und Marcato markiert einen besonders kräftigen Anschlag.

<NotationArticulations />

## Haltebogen und Bindebogen

Ein **Haltebogen** verbindet Noten gleicher Tonhöhe; die Notenwerte werden zu einem gehaltenen Ton zusammengefasst. Ein **Bindebogen** verbindet unterschiedliche Tonhöhen und zeigt an, dass sie gebunden (legato) gespielt werden.

<NotationBows />

## Dynamik

Dynamikzeichen geben an, wie laut oder leise gespielt wird. **p** (*piano*) bedeutet leise, **f** (*forte*) laut. Ein Crescendo (*cresc.*) wird durch einen nach rechts weiter werdenden Keil dargestellt und bedeutet, allmählich lauter zu werden. Ein Decrescendo (*decresc.*) verengt sich nach rechts und bedeutet, allmählich leiser zu werden. In einer Notenzeile bindet `NotationVisual` die Zeichen über `hairpin="crescendo"` oder `hairpin="decrescendo"` ein. Mit `initialDynamic="forte"` beziehungsweise `"piano"` lässt sich ein bereits geltender Dynamikzustand angeben, sodass der Anfangswert nicht unnötig wiederholt wird.

<NotationDynamics />

## Abschlussbeispiel: achtzehn Takte

Das abschließende Testbeispiel bündelt Notationszeichen in achtzehn vollständigen, nummerierten Takten im Violinschlüssel. Die Takte 1 bis 8 und 13 bis 15 stehen im 4/4-Takt, die Takte 9 bis 12 und 16 bis 18 im 3/4-Takt. Die Taktart steht nur am Anfang und beim Wechsel. Es enthält eine Tonartvorzeichnung, einzelne Kreuze, Bs und Auflösungszeichen, Hilfslinien, ganze bis Sechzehntelnoten, Punktierung, Fähnchen und Balkengruppen, Artikulationen oberhalb und unterhalb von Noten, Halte- und Bindebögen, Allegro, rit. und a tempo mit mindestens zwei Notenpositionen Abstand, Crescendo und Decrescendo, Wiederholungszeichen sowie den Schlussstrich. In den letzten sechs Takten stehen ganze, halbe, Viertel- und Achtelpausen.

<NotationOverview />

Bei ausreichend Platz stehen die ersten zwölf Takte zu zweit, die letzten sechs zu dritt in einem System. Auf schmalen Bildschirmen steht jeweils ein Takt pro Zeile. Jede Zeile beginnt mit dem Violinschlüssel und der aktuell gültigen Tonartvorzeichnung; es ist kein horizontales Scrollen nötig. Alle Systeme werden pro Takt aus `NotationVisual` aufgebaut. `renderNotationSvg` ordnet Notenschlüssel, Vorzeichen, Noten und Pausen im Notensystem an und nutzt für gemeinsame musikalische Zeichen und Regeln die Bausteine in `src/components/music/`. Taktzahlen kommen aus `MeasureNumber`, Dynamikzeichen und Keile aus `DynamicsMarks`, der Schlussstrich aus `FinalBar`. `NotationOverview` enthält die Taktdaten; `arrangeNotationSystems` ordnet sie auf Zeilen und wiederholt Schlüssel und Vorzeichnung. Ein gesetztes `accidentals`-Array bezeichnet die neue Tonartvorzeichnung; ein leeres Array hebt sie auf, fehlende Angaben behalten die bisherige Vorzeichnung bei. Bei einem Wechsel werden aufgehobene Vorzeichen am Wechsel mit Auflösungszeichen dargestellt. Einzelne `accidental`-Angaben an Noten verändern die Vorzeichnung nicht. Der Schlüssel bleibt durch das ganze Stück unverändert; die Prüfregel wird mit `assertNoClefChanges` abgesichert.

Für mehrzeilige Darstellungen bestimmen `arrangeNotationSystems` und `alignFirstNotesInSystems` eine gemeinsame Position für das erste Ereignis: am Systemanfang auch bei unterschiedlich vielen Takten pro Zeile, in den folgenden Takten mit einem einheitlichen Abstand zum Taktstrich. Das gilt für Noten ebenso wie für Pausen; eine einzelne ganze Taktpause bleibt mittig und eine einzelne ganze Note steht bei 41 % der Taktbreite. Dabei wird genug Platz für Schlüssel, Taktart, Vorzeichnung, Wiederholungszeichen und gegebenenfalls das Vorzeichen der ersten Note reserviert. Die gemeinsame Klasse `notation-systems` sorgt für gleich hohe Zeilen und damit gleichmäßige Abstände zwischen den Notensystemen, auch wenn nur einzelne Zeilen Dynamikzeichen enthalten. `NotationVisual` übergibt die Position an den Renderer; ohne diese Ausrichtung beginnt die Verteilung mit zusätzlichem Abstand.

| Zeichen im Test | Baustein | Regel oder Verwendung |
|---|---|---|
| Violinschlüssel, Notenköpfe, Hilfslinien und Vorzeichen | `NotationVisual`, `renderNotationSvg` | Am Zeilenbeginn stehen Schlüssel, gegebenenfalls Taktart und gültige Vorzeichnung in dieser Reihenfolge; kein Schlüsselwechsel im Stück. |
| Taktarten 4/4 und 3/4 | `music/time-signature.ts` | Nur am Stückanfang und beim Wechsel anzeigen. |
| Ganze bis Sechzehntelnoten, Punkt, Fähnchen und Balken | `music/rhythm.ts` und `renderNotationSvg` | Balkengruppen bestehen aus zusammenhängenden Achteln oder Sechzehnteln gleicher Dauer. |
| Pausen | `music/rest.ts` und `renderNotationSvg` | Pausen können mit Noten gemischt werden; die ganze Pause in Takt 15 füllt den 4/4-Takt und steht mittig im verfügbaren Taktbereich. |
| Taktzahlen, Takt- und Schlussstriche | `MeasureNumber`, `music/barline.ts`, `FinalBar` | Takte 1 bis 18 sind nummeriert; Takt 18 endet mit dem Schlussstrich. |
| Wiederholungszeichen | `music/barline.ts` | Wiederholung umfasst Takt 5 und 6; das Anfangszeichen folgt dem Schlüssel. |
| Artikulationen | `music/articulation.ts` | Alle Zeichen haben ober- und unterhalb denselben Abstand zum Notenkopf. Bei einem abwärts gerichteten Hals steht das Zeichen oberhalb der Note. |
| Halte- und Bindebögen | `music/curve.ts` | Der Haltebogen verbindet gleiche, der Bindebogen hier unterschiedliche Tonhöhen. |
| Allegro, rit. und a tempo | `TempoLabel`, `music/tempo.ts` | `a tempo` liegt mindestens zwei Notenpositionen nach `rit.`. |
| Piano, Forte und Dynamikkeile | `DynamicsMarks`, `music/dynamics.ts` | Bereits geltende Anfangsdynamik wird nicht erneut am Keil angezeigt. |

Der Bassschlüssel wird wegen der Regel gegen Schlüsselwechsel in diesem Stück nicht gezeigt; er ist separat bei der Klaviaturnotation zu sehen. `TempoHeading` mit Metronomangabe und `RepeatMark` sind alternative Komponenten für die eigenständigen Tempo- und Wiederholungsbeispiele; im Abschlusstest kommen stattdessen `TempoLabel` und die gemeinsame Wiederholungszeichen-Funktion zum Einsatz. Die Klavierklammer gehört zum gesonderten Klaviersystem.

Alle Notenbilder verwenden dieselbe Renderinglogik: Astro-Schaubilder binden `NotationVisual` ein, interaktive Quizbilder rufen `renderNotationSvg` aus `src/lib/notation-renderer.ts` auf. Gemeinsame musikalische Bausteine liegen in `src/components/music/`, Notensystem-Schaubilder in `src/components/notation/`. Ihre Styles stehen in `src/styles/music.css` beziehungsweise `src/styles/notation.css`. Eine zukünftige eigene Tabulaturansicht kann die gemeinsamen Bausteine verwenden und ihre Positionen selbst bestimmen. Der bestehende alphaTab-Player ist davon unabhängig. Zeichen und Regeln werden nicht in einzelnen Übersichten oder Quiz-Komponenten nachgebaut.
