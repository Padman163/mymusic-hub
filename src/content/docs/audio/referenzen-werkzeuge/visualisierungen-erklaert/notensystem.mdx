## Taktstriche

Das zweite Schaubild zeigt die Standardansicht mit einem Taktstrich rechts.

<NotationClickable />

Die Taktstriche lassen sich beim Einbinden der Komponente unabhängig voneinander steuern: `showLeftBar` ist standardmäßig `false`, `showRightBar` standardmäßig `true`. Beispielsweise zeigt `<NotationClickable showLeftBar={true} showRightBar={false} />` nur den linken Taktstrich.

## Notenschlüssel

Jede eigenständige Notenzeile zeigt standardmäßig einen Violinschlüssel. Für ein einzelnes Beispiel kann `clef="bass"` den Bassschlüssel wählen. Innerhalb eines Stücks, das von einer `.astro`-Komponente aufgebaut wird, bleibt der Schlüssel jedoch unverändert; `assertNoClefChanges` prüft das. Mit `clef={false}` wird der Schlüssel ausgeblendet, zum Beispiel bei weiteren Takten oder Systemen desselben Stücks. Die Schlüssel verwenden die gleiche Notenschrift wie die AlphaTab-Beispiele.

## Notenköpfe

Gefüllte und ungefüllte Notenköpfe werden hier ohne Hals dargestellt. Sie sind zunächst nur vorgegeben und können noch nicht angeklickt oder eingezeichnet werden.

<NotationClickable notes={[
  { type: 'filled', step: 0 },
  { type: 'empty', step: 2 },
  { type: 'filled', step: 5 },
  { type: 'empty', step: 8 }
]} />

Über `notes` werden Typ (`filled` oder `empty`) und Position (`step`) festgelegt. `step={0}` entspricht der untersten Linie, jeder weitere Schritt einem Linien- oder Zwischenraumabstand; `8` entspricht der obersten Linie. Die Notenköpfe werden von links nach rechts gleichmäßig verteilt. Zusätzlich sind die erste Hilfslinie unterhalb (`-2`) und oberhalb (`10`) des Systems verfügbar. Ein ungefüllter Notenkopf allein legt ohne weitere Notationszeichen keinen vollständigen Notenwert fest.

## Notenhälse

Für jeden Notenkopf kann über `stem: true` ein Hals eingeblendet werden. Ohne diese Angabe bleibt der Notenkopf ohne Hals. Unterhalb der mittleren Linie zeigt der Hals nach oben, ab der mittleren Linie nach unten.

<NotationClickable clef="treble" notes={[
  { type: 'filled', step: 0, stem: true },
  { type: 'empty', step: 3, stem: true },
  { type: 'filled', step: 4, stem: true },
  { type: 'empty', step: 8, stem: true }
]} />

## Taktarten

Das Schaubild zeigt 2/2, 2/4, 3/4, 4/4, 6/8 und 7/8 in einer Notenzeile. Taktstriche trennen die Beispiele.

<NotationTimeSignatures timeSignatures={[
  { numerator: 2, denominator: 2 },
  { numerator: 2, denominator: 4 },
  { numerator: 3, denominator: 4 },
  { numerator: 4, denominator: 4 },
  { numerator: 6, denominator: 8 },
  { numerator: 7, denominator: 8 }
]} />

Bei `NotationClickable` lassen sich mit `timeSignature` Zähler und Nenner festlegen; ohne Angabe wird keine Taktart angezeigt. Der Zähler muss eine positive ganze Zahl sein, der Nenner eine positive Zweierpotenz. Für die gemeinsame Darstellung nimmt `NotationTimeSignatures` eine Liste dieser Taktarten entgegen.

## Vorzeichen

Das Schaubild zeigt im Violinschlüssel fünf Kreuze (F, C, G, D, A), ihre fünf Auflösungszeichen und anschließend fünf b-Vorzeichen (B, E, A, D, G). Im letzten Takt stehen einzelne Noten jeweils einmal mit Kreuz, Auflösungszeichen und b-Vorzeichen.

<NotationAccidentals />

Über `accidentals` lassen sich die Zeichen `sharp` (Kreuz), `natural` (Auflösungszeichen) und `flat` (b) mit einer Position `step` vorgeben. Sie stehen nach dem Schlüssel und vor einer optionalen Taktart. Einzelne Noten können über die Eigenschaft `accidental` ebenfalls jeweils ein eigenes Vorzeichen erhalten. Die Komponente stellt die Zeichen dar, berechnet aber noch keine Tonart oder Tonhöhenänderung.

## Notenwerte

Mit `duration` zeigt die Komponente ganze (`whole`), halbe (`half`), Viertel- (`quarter`), Achtel- (`eighth`) und Sechzehntelnoten (`sixteenth`) an. Notenkopf, Hals und gegebenenfalls Fähnchen ergeben sich aus dem Notenwert; die Halsrichtung wird automatisch bestimmt.

<NotationClickable clef="treble" notes={[
  { duration: 'whole', step: 2 },
  { duration: 'half', step: 2 },
  { duration: 'quarter', step: 2 },
  { duration: 'eighth', step: 2 },
  { duration: 'sixteenth', step: 2 }
]} />

Aufeinanderfolgende Achtel- oder Sechzehntelnoten desselben Werts können mit demselben `beamGroup`-Namen verbunden werden. Eine Gruppe benötigt mindestens zwei Noten und erhält eine gemeinsame Halsrichtung. Bei unterschiedlichen Tonhöhen wird der Balken geneigt und die Hälse werden bis zum Balken geführt. Gemischte Notenwerte innerhalb einer Gruppe sind noch nicht vorgesehen.

<NotationClickable clef="treble" notes={[
  { duration: 'eighth', step: 2, beamGroup: 'achtel' },
  { duration: 'eighth', step: 4, beamGroup: 'achtel' },
  { duration: 'sixteenth', step: 6, beamGroup: 'sechzehntel' },
  { duration: 'sixteenth', step: 4, beamGroup: 'sechzehntel' }
]} />

Die Beispiele zeigen die Zeichen zur Veranschaulichung; die Komponente prüft noch nicht, ob Notenwerte zusammen zur Taktart passen.

## Klaviaturnotation

Das Klaviersystem zeigt oben den Violin- und unten den Bassschlüssel. Das mittlere C (C4) steht im oberen System auf der ersten Hilfslinie darunter und im unteren System auf der ersten Hilfslinie darüber. Beide Darstellungen liegen hier genau übereinander und zeigen denselben Ton.

<NotationKeyboard />

Der Schlussstrich erstreckt sich über beide Systeme. Mit `rightBarStyle="single"` erscheinen stattdessen die einfachen Taktstriche. Die geschweifte Klammer ist standardmäßig sichtbar und lässt sich beim Einbinden mit `<NotationKeyboard showBrace={false} />` ausblenden.

Die Visualisierung trägt die Tags `Allgemein` und `Notensystem`. Mehr zur geplanten Verwendung steht unter [EXP und Tags](../../exp-und-tags/).


## Auftakt und Wiederholung

Das Beispiel im 4/4-Takt beginnt mit einem Auftakt von einer Viertelnote. Danach folgen die nummerierten Takte 1 bis 4. Das Anfangswiederholungszeichen steht nach dem Notenschlüssel. Die Wiederholungszeichen schließen Takt 2 und 3 ein: Nach Takt 3 werden diese beiden Takte einmal wiederholt, bevor Takt 4 folgt. Der letzte Takt enthält drei Viertelnoten und ergänzt damit den Auftakt zu einem vollständigen 4/4-Takt.

<NotationPickupRepeat showMeasureNumbers={true} />

Taktnummern sind standardmäßig ausgeblendet und werden in diesem Beispiel mit `showMeasureNumbers={true}` eingeblendet.

## Tempoangaben

Das Beispiel zeigt zwei 4/4-Takte mit **Allegro** und der Metronomangabe **Viertelnote = 90** (90 Viertelschläge pro Minute). Im zweiten Takt bedeutet **rit.**, allmählich langsamer zu werden; **a tempo** führt zum ursprünglichen Tempo zurück. Beide Angaben werden über `ritAt` und `aTempoAt` direkt an `NotationClickable` an nullbasierten Notenindizes gebunden. `aTempoAt` muss mindestens zwei Indizes nach `ritAt` liegen; dieselbe oder eine frühere Note ist unzulässig.

<NotationTempo />

## Artikulation

Artikulationszeichen beschreiben, wie ein Ton gespielt und gestaltet wird. Das Beispiel zeigt **Staccato**, **Tenuto**, **Akzent** und **Marcato** jeweils oberhalb und unterhalb einer Note. Die Platzierung kann je nach Notenbild oberhalb oder unterhalb erfolgen: Staccato verkürzt den Ton, Tenuto hält ihn voll aus, der Akzent hebt ihn hervor und Marcato markiert einen besonders kräftigen Anschlag.

<NotationArticulations />

## Haltebogen und Bindebogen

Ein **Haltebogen** verbindet Noten gleicher Tonhöhe; die Notenwerte werden zu einem gehaltenen Ton zusammengefasst. Ein **Bindebogen** verbindet unterschiedliche Tonhöhen und zeigt an, dass sie gebunden (legato) gespielt werden.

<NotationBows />

## Dynamik

Dynamikzeichen geben an, wie laut oder leise gespielt wird. **p** (*piano*) bedeutet leise, **f** (*forte*) laut. Ein Crescendo (*cresc.*) wird durch einen nach rechts weiter werdenden Keil dargestellt und bedeutet, allmählich lauter zu werden. Ein Decrescendo (*decresc.*) verengt sich nach rechts und bedeutet, allmählich leiser zu werden. In einer Notenzeile bindet `NotationClickable` die Zeichen über `hairpin="crescendo"` oder `hairpin="decrescendo"` ein. Mit `initialDynamic="forte"` beziehungsweise `"piano"` lässt sich ein bereits geltender Dynamikzustand angeben, sodass der Anfangswert nicht unnötig wiederholt wird.

<NotationDynamics />

## Abschlussbeispiel: zwölf Takte

Das abschließende Beispiel bündelt die hier gezeigten Notationszeichen in zwölf vollständigen, nummerierten Takten im Violinschlüssel. Die Takte 1 bis 8 stehen im 4/4-Takt; ab Takt 9 wechselt das Beispiel in den 3/4-Takt. Die Taktart steht nur am Anfang und beim Wechsel. Das Beispiel enthält eine Tonartvorzeichnung, einzelne Kreuze, Bs und Auflösungszeichen, ganze bis Sechzehntelnoten, Punktierung, Balkengruppen mit unterschiedlichen Tonhöhen, Artikulationen oberhalb und unterhalb von Noten, Halte- und Bindebögen, Allegro, rit. und a tempo mit mindestens zwei Noten Abstand, Crescendo und Decrescendo, Wiederholungszeichen sowie den Schlussstrich.

<NotationOverview />

Die zwölf Takte sind in drei Notensysteme mit je vier Takten gegliedert. Alle Systeme werden pro Takt aus `NotationClickable` aufgebaut. Der gemeinsame `renderNotationSvg`-Renderer zeichnet Schlüssel, Taktart, Vorzeichen, Noten, Hälse, Balken, Artikulationen, Bögen, Tempoangaben, Wiederholungen und Taktstriche. Taktzahlen kommen aus `NotationMeasureNumber`, Dynamikzeichen und Keile aus `NotationDynamicsMarks`, der Schlussstrich aus `NotationFinalBar`; `NotationDynamics` verwendet dieselbe Dynamik-Komponente auch für das eigenständige Dynamik-Schaubild. `NotationOverview` enthält nur die Taktdaten und ordnet die Komponenten an, es legt keine eigenen Zeichenregeln fest. Der Schlüssel bleibt durch das ganze Stück unverändert; die Prüfregel wird mit `assertNoClefChanges` abgesichert.

Alle Notenbilder verwenden dieselbe Renderinglogik: Astro-Schaubilder binden `NotationClickable` ein, interaktive Quizbilder rufen `renderNotationSvg` aus `src/lib/notation-renderer.ts` auf. Die Styles der Notationskomponenten liegen zentral in `src/styles/notation.css`; neue Komponentenstyles werden dort ergänzt und über eindeutige Notationsklassen eingegrenzt. Neue Notationszeichen und ihre Positionierung werden im Renderer ergänzt; in Übersichten oder Quiz-Komponenten dürfen sie nicht als separate SVGs nachgebaut werden.
