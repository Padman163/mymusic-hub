## 1. Das 5-Linien-System
- Violinschlüssel (G-Schlüssel): Referenziert die Note $G_4$ auf der 2. Notenlinie von unten
- Stammtöne: Feste Zuweisung auf Linien und Zwischenräumen
- Versetzungszeichen: $\sharp$ (Erhöhung um einen Halbton), $\flat$ (Erniedrigung um einen Halbton), $\natural$ (Auflösung)

## 2. Die 6-Linien-Gitarrentabulatur (TAB)
- Saitenzuordnung: 6 Linien repräsentieren die physischen Saiten
- Leserichtung: Unterste Linie = tiefste Saite ($E_2$), oberste Linie = höchste Saite ($E_4$)
- Griffziffern: Ganze Zahl = Bundnummer, $0$ = Leersaite
- Gleichzeitigkeit: Vertikal übereinanderliegende Noten = simultanes Anschlagen

## 3. Das Unisono-Prinzip
- Gitarrenspezifik: Dieselbe absolute Tonhöhe existiert an mehreren Positionen (z. B. $A_2$ = leere A-Saite oder Bund 5 der tiefen E-Saite)
- Tabulatur vs. Standardnotation: TAB definiert den physischen Ort, Notenschrift die Tonhöhe
