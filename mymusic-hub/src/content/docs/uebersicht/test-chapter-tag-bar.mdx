# 🏷️ Test: ChapterTagBar-Komponente

Die **ChapterTagBar** ist eine flexible Komponente zum Anzeigen und Filtern von Metadaten zu Lektionen.

---

## **Modus 1: Display-Modus (Standard - auf Lektionsseiten)**

**Was siehst du:** Elegante Info-Chips oben auf einer Seite, die wichtige Metadaten anzeigen.

<ChapterTagBar 
  tags={["Gitarre", "Praxis", "Rhythmus"]} 
  difficulty="Mittel" 
  dLevel="D1" 
  xp={75}
  filterMode={false}
/>

### Was hier sichtbar sein sollte:
- ✅ **Instrument-Icon** (Gitarre)
- ✅ **Tags**: `Gitarre`, `Praxis`, `Rhythmus` (als bunte Chips)
- ✅ **Schwierigkeit**: `Mittel`
- ✅ **Prüfungsrelevanz**: `D1-relevant`
- ✅ **XP-Wert**: `75 XP` (violett hinterlegt)

### So siehst du es in echten Lektionen:
Diese Chips erscheinen oben auf jeder Lektion und geben dir schnell einen Überblick.

---

## **Modus 2: Filter-Modus (auf Übersichtsseiten)**

**Was siehst du:** Interaktive Filter-Buttons zum Filtern von Lektionen nach Kategorie, Schwierigkeit, etc.

<ChapterTagBar 
  tags={["Gitarre", "Allgemein", "D1-relevant", "D2-relevant", "D3-relevant"]}
  difficulty="Alle"
  filterMode={true}
/>

### Was hier sichtbar sein sollte:
- ✅ **Filter-Buttons**: `Alle`, `Gitarre`, `Allgemein`, `D1-relevant`, `D2-relevant`, `D3-relevant`, `Leicht`, `Mittel`, `Schwer`
- ✅ **Button-Design**: Aktiv = blau, Inaktiv = hellgrau
- ✅ **Interaktivität**: Buttons sind klickbar

### So testest du die Filter:
1. Klick auf einen Button (z.B. "Gitarre")
2. Die Seite sollte darunter Lektionen filtern (würde mit echten Lektionen sichtbar sein)
3. Klick auf "Alle" → zeigt wieder alle Lektionen

## **Info für Entwickler**

**Props der Komponente:**

```astro
interface Props {
  tags?: string[];              // Array von Tags
  difficulty?: string;          // "Basis" | "Mittel" | "Fortgeschritten" | "Master"
  dLevel?: string;             // "D1" | "D2" | "D3" | "Produktion"
  xp?: number;                 // XP-Punkte dieser Lektion
  filterMode?: boolean;        // true = Filter-Buttons, false = Info-Display
}
```

## **Häufige Fragen**

**F: Warum sind die Filter nicht funktional?**  
A: Dieser Test zeigt nur die UI. Mit echten Lektionen-Listen würde JavaScript die Seiten-Elemente (mit `data-tags` Attribut) filtern.

**F: Können Buttons mehrfach selektiert werden?**  
A: Ja! Mit Vanilla-JS können mehrere Filter gleichzeitig aktiv sein.

**F: Wo werden die Tags/Filter gespeichert?**  
A: Aktuell im Browser-Speicher (`sessionStorage`). Optional könnten wir `localStorage` nutzen.
