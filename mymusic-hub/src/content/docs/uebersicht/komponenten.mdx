## 1. Feature Card Component

Die `FeatureCard`-Komponente zeigt Features im GitHub-Issue-Design an:

### Props:
- `id`: string (z.B. `"FEAT-101-A"`)
- `title`: string
- `status`: `'Geplant' | 'In Arbeit' | 'Bereit' | 'Konzept'`
- `category`: string
- `difficulty?: string`
- `tags?: string[]`
- `comments?: Array<{ author: string; role: 'Dev' | 'Didaktik' | 'Audio'; text: string }>`

## 2. Chapter Tag Bar

### Display-Modus (Standard für Lektionsseiten)

Zeigt elegante Chips für Tags, Schwierigkeit, Diploma-Level und XP:

<ChapterTagBar 
  tags={['Gitarre', 'D1-relevant', 'Praxis']} 
  difficulty="Mittel" 
  dLevel="D1" 
  xp={50}
  filterMode={false}
/>

**Use Case:** Am Seitenanfang von Lektionen, um Metadaten anzuzeigen.

### Filter-Modus (für Übersichtsseiten)

Interaktive Button-Leiste zum Filtern von Inhalten:

<ChapterTagBar filterMode={true} />

**Use Case:** Auf Index- oder Übersichtsseiten, um Inhalte zu filtern.

### Props:
- `tags?: string[]`
- `difficulty?: string` – Eine der: `'Basis' | 'Mittel' | 'Fortgeschritten' | 'Master'`
- `dLevel?: string` – Eine der: `'D1' | 'D2' | 'D3' | 'Produktion'`
- `xp?: number`
- `filterMode?: boolean` (default: `false`)

## 3. Interactive Score Trainer

Ein progressives 3-Stufen-Trainings-Tool:

<InteractiveScoreTrainer 
  initialMode={1}
  scale="C-Dur"
  exerciseTitle="Anfänger: TAB-Eingabe"
/>

### Features:

**Stufe 1: TAB (Anfänger)**
- 6-Saiten-Gitarren-TAB mit Bundzahlen 0–12
- Interaktive Eingabe
- Dreiklang-Markierung (1 = Grundton, 3 = Terz, 5 = Quinte)

**Stufe 2: Standard-Notation (Mittel)**
- 5-Linien-System mit Violinschlüssel (𝄞)
- Notenköpfe, Vorzeichen (♯, ♭, ♮)
- Notenwerte: Ganze, Halbe, Viertel, Achtel
- Artikulation: Staccato, Legato, Tenuto, Akzent
- Dynamik: pp bis ff

**Stufe 3: Bassschlüssel (Fortgeschritten)**
- F-Bassschlüssel (𝄢)
- Tonart-Vorzeichenwahl (bis ±3 ♯/♭)
- Tonarten: C, G, D, A, F, B, Es

### Props:
- `initialMode?: 1 | 2 | 3` (default: `1`)
- `scale?: string` (z.B. `"D-Dur"`)
- `exerciseTitle?: string`

## 4. XP Tracker

Ein Gamification-Dashboard mit localStorage-Persistierung:

<XpTracker showPillars={true} />

### Features:

- **Gesamt-XP** anzeigen
- **Level-Gate-Tracking**: „80% + Quiz 105 erfolgreich"
- **3 Fähigkeits-Säulen** mit Fortschrittsbalken:
  - 🎸 Griffbrett-Motorik
  - 🥁 Rhythmus & Backing-Track
  - 🎵 Notation & Mikro-Songwriting
- **localStorage-Persistierung**: `mymusic_xp_state`
- **Export/Import** der XP-Daten als JSON

### Public API:

```javascript
// XP hinzufügen und auf eine Säule verteilen
window.addXp(10, 'motor');   // Griffbrett-Motorik
window.addXp(15, 'rhythm');  // Rhythmus
window.addXp(20, 'notation'); // Notation
```

### Props:
- `compact?: boolean` (default: `false`)
- `showPillars?: boolean` (default: `true`)

## Content Schema Erweiterung

Das `src/content.config.ts` wurde um optionale Metadaten erweitert:

```typescript
export const collections = {
  docs: defineCollection({
    loader: docsLoader(),
    schema: docsSchema({
      extend: z.object({
        tags: z.array(z.string()).optional(),
        difficulty: z.enum(['Basis', 'Mittel', 'Fortgeschritten', 'Master']).optional(),
        dLevel: z.enum(['D1', 'D2', 'D3', 'Produktion']).optional(),
        xpReward: z.number().optional(),
      }),
    }),
  }),
};
```

### Beispiel Frontmatter:

```yaml
---
title: "Level 100: Erste Schritte"
tags: ['Gitarre', 'D1-relevant', 'Praxis']
difficulty: 'Basis'
dLevel: 'D1'
xpReward: 50
---
```
