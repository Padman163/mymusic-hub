## 🎮 Neue Komponenten-Übersicht

Diese Seite dokumentiert alle neuen Komponenten, die in dieser Version hinzugefügt wurden:

1. **FeatureCard** – GitHub-Issue-ähnliche Feature-Tracker
2. **ChapterTagBar** – Filter- und Metadaten-Display
3. **InteractiveScoreTrainer** – 3-Stufen TAB/Notation/Bass-Editor
4. **XpTracker** – Gamification-Dashboard mit XP-Tracking

---

## 1. Feature Card Component (`FeatureCard.astro`)

Die `FeatureCard`-Komponente zeigt Features im **GitHub-Issue-Design** an.

### Props:
- `id`: string – eindeutige Feature-ID (z.B. `"FEAT-101-A"`)
- `title`: string – Titel des Features
- `status`: `'Geplant' | 'In Arbeit' | 'Bereit' | 'Konzept'` – Status-Badge mit Farbe
- `category`: string – Kategorie (z.B. `"Praxis 101"`, `"Gamification"`, `"Songwriting"`)
- `difficulty?`: string – optional: `'Basis'`, `'Mittel'`, `'Fortgeschritten'`, `'Master'`
- `tags?`: string[] – optional: Filterbare Tags
- `comments?`: Array – optional: Developer/Didaktik/Audio-Kommentare

### Layout:
- **Header:** ID-Badge, Titel, Status-Badge (farbcodiert), Kategorie-Badge
- **Hauptbereich:** `<slot />` für detaillierte Beschreibung und Teilaufgaben
- **Tag-Zeile:** Schnelle Filterung nach Tags
- **Aufklappbarer Footer:** `<details>` mit Kommentaren, gruppiert nach Rolle (Dev/Didaktik/Audio)

### Use Case:
Auf Übersichtsseiten und Feature-Tracking-Dashboards, um den Status und die Diskussion von Features zentral zu verwalten.

## 2. Chapter Tag Bar (`ChapterTagBar.astro`)

Die `ChapterTagBar`-Komponente zeigt **Metadaten und ermöglicht clientseitige Filterung**.

### Props:
- `tags?`: string[] – Tags aus dem Content-Metadaten
- `difficulty?`: string – `'Basis' | 'Mittel' | 'Fortgeschritten' | 'Master'`
- `dLevel?`: string – Diploma-Level: `'D1' | 'D2' | 'D3' | 'Produktion'`
- `xp?`: number – XP-Wert für diese Lektion
- `filterMode?`: boolean – `false` (Display) oder `true` (Filterbar)

### Display-Modus (`filterMode={false}`, Standard):
Zeigt elegante **Chips** am Seitenanfang von Lektionen:
- **Instrument:** `Gitarre` / `Allgemein`
- **Prüfungsrelevanz:** `D1-relevant`, `D2-relevant`, `D3-relevant`
- **Schwierigkeitsstufe:** `Basis`, `Mittel`, `Fortgeschritten`, `Master`
- **XP-Wert:** z.B. `+50 XP`

Jedes Chip hat ein passend farbiges Icon/Emoji und ist am Rand abgerundet.

### Filter-Modus (`filterMode={true}`):
Rendert eine **interaktive Filterleiste** mit Buttons:
- Buttons für `Alle`, `Gitarre`, `Allgemein`, `D1-relevant`, `D2-relevant`, `D3-relevant`, `Leicht`, `Mittel`, `Schwer`
- **Vanilla-JS:** Filtert DOM-Elemente mit `data-tags`-Attributen
- **State:** In `sessionStorage` oder Komponenten-State

### Use Case:
- **Display-Modus:** Am Anfang jeder Lektion, um Kontext und Relevanz zu zeigen
- **Filter-Modus:** Auf Übersichtsseiten (Index, Kapitel-Übersicht), um Inhalte zu filtern

## 3. Interactive Score Trainer (`InteractiveScoreTrainer.astro`)

Das **progressive 3-Stufen-Trainings-Tool** für Notation und TAB.

### Props:
- `initialMode?`: `1 | 2 | 3` – Startstufe (default: `1`)
- `scale?`: string – Tonleiter/Scale (z.B. `"C-Dur"`, `"A-Moll"`)
- `exerciseTitle?`: string – Titel der Übung

### 3 Schwierigkeitsstufen (Tabs):

#### **Stufe 1 – Gitarren-Standard (TAB)**
- Interaktives **6-Linien-TAB-Raster**
- Benutzer trägt **Bundzahlen** (0–12) auf den 6 Saiten ein
- Klickbar: Felder zum Eingeben oder Löschen
- Farbcodierung nach **Intervall-Palette** (optional)
- Validierung gegen Referenz-TAB

#### **Stufe 2 – Standard-Notation (Violinschlüssel)**
- Interaktives **5-Linien-System** im Violinschlüssel ($\mathcal{G}_8$)
- Benutzer setzt:
  - **Notenköpfe** (durch Klick auf Linie/Zwischenraum)
  - **Vorzeichen:** ♯ (Kreuz), ♭ (Be), ♮ (Auflösungszeichen)
  - **Notenwerte:** Ganze, Halbe, Viertel, Achtel, Sechzehntel
- Farben nach Intervallen
- Validierung gegen Referenz-Notation

#### **Stufe 3 – Master (Bassschlüssel)**
- **5-Linien-System** im **F-Bassschlüssel** (Violinschlüssel 8va bassa)
- Benutzer wählt **Tonart-Vorzeichen:** C, G, D, A, F, B, Es (bis 3 ♯/♭)
- Setzt Notenköpfe wie Stufe 2
- Validierung mit Bassschlüssel-Linienabständen

### Zusatz-Features (Toolbar):

#### **Modus: „Dreiklang markieren"**
- Markiert automatisch **Grundton** (#F38181), **Terz** (#EAA0E3 / #D382DC), **Quinte** (#64C4ED)
- Hilft Schülern, Akkordaufbau zu visualisieren

#### **Modus: „Artikulation setzen"**
- Buttons für:
  - **Staccato-Punkt** (·)
  - **Legato-Bogen** (_)
  - **Tenuto-Strich** (─)
  - **Akzentkeil** (>)
  - **Dynamikstufen:** $pp$, $p$, $mp$, $mf$, $f$, $ff$

#### **Prüf-Button: „Eingabe prüfen & XP sammeln"**
- Vergleicht Benutzer-Input mit Referenz
- Gibt visuelles Feedback: ✅ Grün (richtig) oder ❌ Rot (falsch)
- Ruft `window.addXp()` auf bei Erfolg
- Zeigt Fehlerpunkte

### Use Case:
Lektion 104 (Gamification-Vorstufe): Benutzer trainiert progressive Notation von TAB → Standard → Bass, mit Farbcodierung und XP-Reward.

## 4. XP Tracker (`XpTracker.astro`)

Das **Gamification-Dashboard-Widget** für Skill-Tracking.

### Props:
- `showPillars?`: boolean – zeige die 3 Säulen (default: `true`)

### Features:

#### **localStorage-Persistierung**
- Key: `mymusic_xp_state`
- Speichert: Gesamt-XP, Pro-Säule-XP, Level, Progress zu nächstem Level
- Format: JSON `{ totalXp: number, pillars: { motor: number, rhythm: number, notation: number }, ... }`

#### **Gesamt-XP & Fortschritt**
- Zeigt **Gesamt-XP** prominent oben
- **Fortschrittsbalken** für nächstes Level (z.B. 0/100 XP → Level 2)
- **Level-Gate-Anzeige:** z.B. „Level 100 Praxis-Freischaltung bei 80% + bestandenem Quiz 105"

#### **3 Säulen (Skill-Pillars)**
1. **Griffbrett-Motorik** (motor)
   - XP aus Stufe 1 (TAB-Editor)
   - Fortschrittsbalken

2. **Rhythmus & Backing-Track** (rhythm)
   - XP aus DrumPattern, BassPattern, GuitarPattern-Übungen
   - Fortschrittsbalken

3. **Notation & Mikro-Songwriting** (notation)
   - XP aus Stufe 2/3 (Standard/Bass), ScorePattern-Übungen
   - Fortschrittsbalken

Jede Säule hat:
- **Name** und **Icon** (🎸, 🥁, 🎼)
- **Aktuellen XP** und **Gesamt-Target** für diesen Pillar
- **Farbigen Fortschrittsbalken**

#### **Public API für XP-Hinzufügen**
```javascript
window.addXp(amount, pillar)
```
- `amount`: number – XP-Punkte (z.B. 50)
- `pillar`: `'motor' | 'rhythm' | 'notation'` – welche Säule

Beispiele:
```javascript
window.addXp(50, 'motor')    // +50 XP zu Griffbrett-Motorik
window.addXp(30, 'rhythm')   // +30 XP zu Rhythmus
window.addXp(20, 'notation') // +20 XP zu Notation
```

#### **Export & Import** (optional)
- Button zum Export des XP-State als JSON (zum Backup)
- Button zum Import aus JSON (zum Restore)

### Use Case:
Widget auf der Startseite oder im Sidebar, um Fortschritt zu tracken. Wird von allen anderen Komponenten (InteractiveScoreTrainer, FeatureCard-Validierung, etc.) aufgerufen.

## 🎨 Intervall-Farbpalette

Alle Komponenten verwenden diese 12er-Palette für **musikalische Intervalle**:

| Intervall | Farbe | Hex | Bedeutung |
|-----------|-------|-----|----------|
| 1 | 🔴 | `#F38181` | Grundton (Root) |
| ♭2 | 🟠 | `#FFAAA6` | Kleine Sekunde |
| 2 | 🟠 | `#F4C7AB` | Große Sekunde |
| ♭3 | 🟣 | `#EAA0E3` | Kleine Terz |
| 3 | 🟣 | `#D382DC` | Große Terz |
| 4 | 🟣 | `#B862D3` | Quarte |
| ♭5 | 🔵 | `#7F8BE8` | Verminderte Quinte (Tritonus) |
| 5 | 🔵 | `#64C4ED` | Quinte (Perfect Fifth) |
| ♭6 | 🔵 | `#52DEE5` | Kleine Sexte |
| 6 | 🟢 | `#6BE4C6` | Große Sexte |
| ♭7 | 🟢 | `#83E8BA` | Kleine Septime |
| 7 | 🟡 | `#CBDD7B` | Große Septime |

Diese Farben werden in allen Komponenten konsistent verwendet für:
- **Notenköpfe** im InteractiveScoreTrainer
- **Griffbrett-Visualisierung** in FretboardClickable
- **TAB-Eingabe-Raster** im Trainer
- **Akkord-Markierung** (Grundton, Terz, Quinte)

## 📋 Integration in Content-Schema

Alle Seiten können diese neuen Metadaten nutzen:

```yaml
---
title: "Meine Lektion"
tags: ['Gitarre', 'D1-relevant', 'Praxis', 'Theorie']
difficulty: 'Mittel'
dLevel: 'D1'
xpReward: 50
---
```

Diese Werte werden dann von `ChapterTagBar` und anderen Komponenten gelesen und angezeigt.

## 🧪 Testing

Öffne die Browser-**Developer Tools** (F12) und versuche:

```javascript
// XP hinzufügen
window.addXp(50, 'motor')
window.addXp(30, 'rhythm')
window.addXp(20, 'notation')

// XP-State anschauen
console.log(JSON.parse(localStorage.getItem('mymusic_xp_state')))

// XP zurücksetzen
localStorage.removeItem('mymusic_xp_state')
```
