# 🏷️ Feature: ChapterTagBar Component

**Wofür?** Zeigt Metadaten eines Kapitels elegant an (Schwierigkeit, D-Level, XP-Reward) oder ermöglicht dynamische Client-seitige Filterung von Inhalten basierend auf Tags. Zwei Modi: Display (Lektionsseite) und Filter (Übersichtsseite).

---

## Live-Demo: Display-Modus

<ChapterTagBar 
  tags={['Gitarre', 'D1-relevant']} 
  difficulty="Mittel" 
  dLevel="D1" 
  xp={50}
  filterMode={false}
/>

**Das siehst du:** Elegante graue Info-Chips oben auf einer Lektionsseite.

---

## 🎯 Props & Modi

### Props

```typescript
interface Props {
  tags?: string[];           // z.B. ['Gitarre', 'D1-relevant', 'Praxis']
  difficulty?: string;       // 'Basis', 'Mittel', 'Fortgeschritten', 'Master'
  dLevel?: string;           // 'D1', 'D2', 'D3', 'Produktion'
  xp?: number;               // XP-Reward für diese Lektion (z.B. 50)
  filterMode?: boolean;      // Display (false) vs. Filter (true) Modus
}
```

## 🔍 Modus 2: Filter (auf Übersichtsseiten)

### Verwendung

```astro
---
title: "Alle Lektionen"
description: "Durchsuche und filtere alle Kapitel"
---

import ChapterTagBar from '../../../components/ChapterTagBar.astro';

# 📚 Kapitelübersicht

<ChapterTagBar filterMode={true} />

[Danach: Liste aller Kapitel mit data-tags Attributen]

<div class="chapter-list">
  <div data-tags="Gitarre D1-relevant Praxis Motorik">
    <!-- Kapitel 1 -->
  </div>
  <div data-tags="Allgemein D1-relevant Theorie">
    <!-- Kapitel 2 -->
  </div>
</div>
```

### Was du siehst

**Filter-Leiste mit Buttons:**

```
[Alle] [🎸 Gitarre] [📚 Allgemein] [🔵 D1-relevant] [🟠 D2-relevant] [🔴 D3-relevant]
[💪 Leicht] [🎯 Mittel] [🚀 Schwer] [🏆 Master]
```

Buttons sind **interaktiv** - klick drauf und die Elemente darunter filtern sich!

### Filterungs-Logik

```javascript
// Wenn du klickst "🎸 Gitarre":
// → Zeige nur Kapitel mit data-tags="...Gitarre..."

// Wenn du "🔵 D1-relevant" UND "💪 Leicht" klickst:
// → Zeige nur Kapitel mit BEIDEN Tags

// Klick auf aktiven Button:
// → Deaktiviert den Filter (toggle)

// Klick auf "Alle":
// → Setzt alle Filter zurück
```

## 📋 Technische Details

### localStorage für Filter-State

Der aktuelle Filter-State wird **nicht** gespeichert (absichtlich). Jeder Seitenbesuch startet mit allen Kapiteln.

Falls du Filter-Memory möchtest:

```javascript
// Speichern
localStorage.setItem('chapter-filter', JSON.stringify(activeFilters));

// Laden
const saved = localStorage.getItem('chapter-filter');
```

### CSS Styling

- **Display-Modus:** Graue Chips, horizontal arrangiert
- **Filter-Modus:** Buttons mit Hover-Effekt, Aktivstatus farbig
- **Responsive:** Auf Mobile stacked/wrapped

### Performance

- ✅ Vanilla JavaScript (kein Framework)
- ✅ O(n) Filterungs-Algorithmus
- ✅ Keine API-Calls
- ✅ Instant-Feedback

## 💡 Best Practices

1. **Immer data-tags setzen** auf Kapitel-Elementen (Display-Modus)
2. **Tags im Frontmatter** und in ChapterTagBar **konsistent halten**
3. **Max 5-6 Tags pro Kapitel** - sonst zu viel Info
4. **Eindeutige Tag-Namen** verwenden (z.B. "D1-relevant" statt "D1")
5. **Auf Filterergebnis checken** - keine leeren Ergebnisse

## 🐛 Debugging

**Filter funktioniert nicht?**

1. Öffne Browser-Console (F12)
2. Überprüfe `data-tags` Attribute auf HTML-Elementen
3. Stelle sicher, dass Tag-Namen **exakt** gleich sind
4. Beispiel:
   ```javascript
   // In der Console:
   document.querySelectorAll('[data-tags]').forEach(el => {
     console.log(el.getAttribute('data-tags'));
   });
   ```
